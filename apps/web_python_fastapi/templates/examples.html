Cross-runtime handoff in one demo

A custom Python orchestrator hands work to a graph-style peer, then a crew-style peer — same protocol, no shared agent framework.

  1. 1. Handshake
    Orchestrator hellos researcher and writer; sessions exchange.
  2. 2. Research offer
    task.offer with research.web. Graph-style adapter emits progress and events.
  3. 3. Write offer
    Orchestrator forwards notes via write.brief. Crew-style adapter drafts the brief.
  4. 4. Audit
    MemoryAuditLog records hello, offer, accept, progress, and result.
