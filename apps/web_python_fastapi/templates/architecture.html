Peers, transports, protocol, adapters — and where standards sit

A2AConnect is the product layer that makes mixed-runtime fleets operable. It does not replace LF A2A or MCP.

Connection flows

  1. 1. Discovery & handshake
    hello → hello.ack (sessionId) → capabilities.query / announce
  2. 2. Capability negotiation
    task.offer lists requiredCapabilities; mismatch → task.reject
  3. 3. Task handoff
    offer → accept/reject → start → progress/events → result/failed
  4. 4. Streaming
    task.progress + event on the same transport; buffer for backpressure
  5. 5. Policy & audit
    before_offer / before_accept gates; MemoryAuditLog for trails
