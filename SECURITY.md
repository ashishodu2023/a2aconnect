# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Email the maintainers via the GitHub security advisory flow on
[ashishodu2023/a2aconnect](https://github.com/ashishodu2023/a2aconnect/security).

Do not file public issues for undisclosed vulnerabilities.

## Scope notes

- Local Gateway preview (`StaticTokenGate`, `TokenBucket`) is for demos — not production auth.
- HTTP JSON stub is in-process unless you deliberately wire real network I/O.
